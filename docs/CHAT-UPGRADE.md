## 2. สถาปัตยกรรมใหม่

```
ผู้ใช้พิมพ์
   │
   ├─ POST /api/gemini/chat-stream   (SSE)
   │     event: meta   → โทน + แหล่งข้อมูล
   │     event: delta  → ข้อความทีละส่วน
   │     event: done   → ข้อความเต็ม
   │     event: error  → ข้อความผิดพลาด
   │
   ├─ ถ้า SSE ใช้ไม่ได้ → /api/gemini/chat-reply (แบบเดิม)
   └─ ถ้าไม่มีคีย์/ออฟไลน์ → เครื่องคำนวณ quant ในเครื่อง
```

ไฟล์ใหม่:

| ไฟล์ | หน้าที่ |
|---|---|
| `src/services/chatStreamCore.ts` | แกนกลางล้วน ๆ (ไม่มี I/O): โทน, prompt, รายการแหล่งข้อมูล, ตัวแยก SSE, ตัวกรองคำต้องห้าม, ตัวดึงเหตุผล |
| `src/services/chatStreamClient.ts` | เรียก SSE + fallback 3 ชั้น + ยกเลิกได้ |
| `src/components/chat/MarkdownLite.tsx` + `markdownLite.ts` | ตัวแปลง markdown ขนาดจิ๋วที่ปลอดภัย (สร้าง React element ไม่ใช้ innerHTML) |
| `src/components/chat/ChatMessageItem.tsx` | บับเบิลข้อความ + แผงเปิดเผยที่มา/เหตุผล |
| `src/components/chat/ChatComposer.tsx` | ช่องพิมพ์ auto-grow + ปุ่มส่ง/หยุด |
| `src/components/ChatModal.tsx` | เขียนใหม่ทั้งไฟล์ |

## 3. กติกา Brand Book ที่บังคับใช้ในโค้ด

1. **ห้ามคำต้องห้าม** — `FORBIDDEN_WORDS` แทนคำว่า ด่วน! / พลาดไม่ได้ / ตอนนี้เลย / รีบเลย / เหลือที่เดียว / การันตีกำไร ทั้งใน prompt (สั่งโมเดล) และใน `sanitizeVoice()` (ตาข่ายชั้นสองฝั่งหน้าจอ)
2. **ทุกคำตอบบอกที่มา + เหตุผล 3 ข้อ** — บังคับใน prompt ข้อ 3 และ 6 แล้วแสดงผลใน UI
3. **ผู้ใช้คุมได้** — เลือกโทนได้ หยุดได้ ปิดได้ ปิดหน้าต่าง = ยกเลิกสตรีมทันที
4. **คำตอบสั้น อ่านจบไว** — จำกัด 180 คำ ใน prompt, จำกัด input 800 ตัวอักษร, `marketBrief` 2,400 ตัวอักษร
5. **ไม่เร่ง ไม่ขู่** — ห้ามใช้ตัวพิมพ์ใหญ่/สี/นาฬิกานับถอยหลังเป็นตัวกระตุ้น (ทั้งใน prompt และใน UI)

## 5. วิธีเปิดโหมด Gemini (สตรีมจริง)

1. เปิดแอป → ไอคอนเฟืองตั้งค่า → ใส่ **Gemini API Key**
2. หรือตั้งฝั่งเซิร์ฟเวอร์: `GEMINI_API_KEY=...` ใน `.env` (อย่า commit คีย์ — ไฟล์ `.env` ถูก ignore แล้ว)
3. ตรวจว่าปลายทางทำงาน:
   ```bash
   curl -s -X POST http://localhost:3000/api/gemini/chat-stream \
     -H 'Content-Type: application/json' \
     -d '{"query":"BTC น่าสนใจไหม","tone":"coach","sources":["ราคาคริปโต 5 ตัว"]}'
   ```
   - ไม่มีคีย์ → `400 {"error":"Missing Gemini API Key"}`
   - มีคีย์ → สตรีม `event: meta` → `event: delta` → `event: done`

## 7. ต่อยอดที่แนะนำ (รอบถัดไป)

1. **Function calling** ให้ AI สั่งหน้าจอได้ เช่น "ขอดูกราฟ BTC" → เปลี่ยนสินทรัพย์/เปิดข่าว (โครง `executeAction()` พร้อมต่อ)

3. **เสียงอ่านคำตอบ** (Web Speech) พร้อมปุ่มปิด — ต้องขออนุญาตก่อนเล่นเสียง
4. **วัตประสิทธิภาพจริง**: เก็บ `latencyMs` ลงสถิติรายวัน เพื่อดูว่าโหมดไหนตอบช้าที่สุด
5. **เทสต์ E2E** ด้วย Playwright เมื่อมี API key ใน CI (ตอนนี้ mock SSE ไว้แล้ว)
