# Dedupe pass — 4 Nov 2026

Scope: find duplicated code/objects in the app and collapse each to **one source of
truth**, without changing behaviour or the Calm System look.

Verified after every step: `tsc --noEmit`, `tsc -p tsconfig.server.json`,
`vitest run` (175 passed), `vite build`.

## What was merged

| Duplicate | Before | After |
| --- | --- | --- |
| Number/time formatters (`formatPrice`, `formatTime`, `formatClock`, `formatDate`) | 8 local copies across 8 files, each with its own rounding | `src/utils.ts` → `formatNumber`, `formatPercent`, `formatCompact`, `formatTime`, `formatClockTime`, `formatDate`, `changeToneClass` |
| Market brief for the AI prompt | `buildMarketContextBrief` (aiChatService) + `buildMarketBrief` (chatStreamClient) — two different snapshots | `buildMarketBrief` exported from `services/chatStreamCore.ts`, now carrying the union of both (P/E, sector, news titles) |
| Chat system prompt | inline prompt in `/api/gemini/chat-reply` had drifted from the streaming prompt | both use `buildChatPrompt({ query, marketBrief, tone, sources })` |
| Palette definition | `CALM_BRAND` declared twice in `mascot/tokens.ts` (66 lines of hex) | one `CALM_BRAND`; `RUST_MODERN_COLORS` reads from it |
| Interactive `transition-*` rule | two global blocks (`@layer base` + plain `button, a`) | one rule in `@layer base` with an explicit property list |
| Thai / Foreign stock cards | 2 files, ~85 % identical markup | `components/stocks/StockCardShell.tsx` + two thin cards that only compute their numbers |

## Behaviour notes

- The foreign card keeps its 52-week bar and `useThb` conversion; the Thai card keeps
  its dividend row. Both are now optional props of the shell, so no card lost a row.
- `formatPercent` prints `0.00%` (not `+0.00%`) for an exactly-flat change, and
  `formatCompact` renders sub-million volumes as `500.0K` instead of `0.5M`.
  Both are intentional; no other output changed.
- `/api/gemini/chat-reply` now returns `400 { error: 'Missing query' }` for an empty
  query instead of calling Gemini with an empty prompt.

## Deliberately not merged

- `ForexDetailModal` ↔ `SignalDetailModal` — 139 shared long lines, but the two read
  from different data shapes and each owns its own fetch/state. Worth a separate
  pass with tests around both dialogs, not a drive-by merge.
- `CryptoCard` ↔ `ForexCard` — only 24 lines of markup overlap; data shapes differ.
