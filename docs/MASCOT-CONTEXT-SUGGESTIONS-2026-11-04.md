# Mascot upgrade — ทางลัดตามหน้าต่าง (context-aware shortcuts)

วันที่: 2026-11-04 · branch `arena/64bd61d7-motorboy-ai-auto-api-trading` (ฐาน `48624b5`)

## สิ่งที่ขอ
> "มาสคอต AI อยู่ในหน้าต่างไหน ฟีเจอร์ไหน จะเน้นเรื่องนั้น ๆ แต่ยังมีความยืดหยุ่นต่อทุกคำถาม
> แค่จะเสนอทางลัดของคำถามของหน้านั้นแบบอัตโนมัติและไม่ตายตัว … รวดเร็ว ประหยัดเวลา
> แบบเป็นอิสระ ไม่มีการล็อคค่าคำสั่งตายตัว"

## ปัญหาเดิม
- มาสคอตรู้ว่าอยู่หน้าต่างไหน (`windowContext`) แต่ใช้แค่แสดงบรรทัด `📍 ชื่อหน้าต่าง`
- ทางเข้าเดียวคือช่องพิมพ์เปล่า ๆ ที่มี placeholder ตัวอย่างคำสั่งตายตัว ("เช่น ดู BTC")
- ผู้ใช้ต้องคิดเองทุกครั้งว่าจะถามอะไรในหน้านั้น → ช้า ไม่ประหยัดเวลา
- ถ้าใส่ "เมนูคำสั่ง" แบบตายตัว จะกลายเป็นการล็อคคำถาม ซึ่งขัดกับข้อกำหนดเรื่องอิสระ

## วิธีแก้: สร้างทางลัดจากบริบทจริง + ข้อมูลสด (ไม่ใช่ลิสต์ตายตัว)

### 1) `src/mascot/suggestions.ts` (ใหม่)
ตัวสร้างทางลัดแบบ pure function — ไม่มี network ไม่มี side effect

```ts
buildMascotSuggestions({
  windowContext, cryptoList, signals, forexRates, thaiStocks, foreignStocks,
  watchlist, drawdownBreaches, worstDrawdownPct, recentIds, seed, now, max,
}) : MascotSuggestion[]
```

| ส่วน | รายละเอียด |
| --- | --- |
| `SURFACE_RECIPES` | ชุด "สูตร" ต่อหน้าต่าง 17 แบบ (5 แดชบอร์ด + 12 โมดัล) แต่ละสูตรดึงข้อมูลสดมาใส่ในประโยค |
| `universalRecipes` | การ์ดเสี่ยง (เมื่อมี drawdown เกินเกณฑ์) และสรุป watchlist — ใช้ได้ทุกหน้า |
| `EXPLORE_POOL` | 10 คำถามนอกเรื่อง (RSI, funding rate, วินัยเทรด, จิตวิทยา…) สุ่ม 1 ข้อต่อการเรียก |
| scoring | `weight` + jitter จาก `hash(id:seed:bucket)` − 40 ถ้าเพิ่งใช้ไป |
| bucket | 15 นาที → ลิสต์เปลี่ยนเองเป็นระยะโดยไม่กะพริบ |

ตัวอย่างที่สร้างจริง (ข้อมูลสมมติ):

| หน้าต่าง | ทางลัดที่ได้ | ที่มาของตัวเลข |
| --- | --- | --- |
| คริปโต | `BTC ไปทางไหนต่อ` → "ตอนนี้ BTC อยู่ที่ 71,858.00 (-3.19%) …" | ราคาจริงจากฟีด |
| คริปโต | `อธิบายสัญญาณ BTC` → "(SL 74,058.57 / TP 67,823.63)" | สัญญาณจริง |
| หุ้นไทย | `PTT น่าสนไหม` / `ปันผลตัวไหนดี` / `CPALL P/E 22.1` | ThaiStock ที่แพง/ถูกสุด |
| หุ้น US | `AAPL ห่างพีค -23.1%` | คำนวณจาก `high52w` |
| Drawdown | `พอร์ตย่อตัวเท่าไร` → "3 ตัวเกินเกณฑ์ แย่สุด 21.09%" | `drawdownBreaches` |
| ทุกหน้า | 1 ชิป `EXPLORE` หมุนเวียน | สุ่มจาก 10 ข้อ |

### 2) UI ในบับเบิล (`MascotOverlay.tsx`)
- แถบ "ทางลัดของหน้านี้" (`data-testid="mascot-suggestions"`) ใต้ข้อความ + ปุ่ม **สุ่มใหม่** (`Dices`)
- ชิปแต่ละอัน: ไอคอน 2.5px, ข้อความ 10px, `title` = คำถามเต็ม, `data-origin` = CONTEXT / LIVE_DATA / RISK / EXPLORE
  - สีขอบแดงอ่อนเฉพาะ `RISK`, สีตัวอักษร signal เฉพาะ `EXPLORE`
- กดชิป → เติมข้อความลงช่องแล้วส่งทันที (เส้นทางเดียวกับพิมพ์เอง — `sendText()`)
- จำรหัสชิปที่เพิ่งใช้ใน `localStorage` (`trading_engine_mascot_suggestions_v1`) → ชิปเดิมไม่โผล่ซ้ำติดกัน

### 3) ความอิสระ (ไม่มีล็อค)
- **ไม่มี whitelist คำสั่ง**: `sendText()` ส่งข้อความดิบไปที่ `/api/gemini/mascot-action` ทุกกรณี
  (เดิมก็ไม่มี — รอบนี้เขียนเป็นสัญญาชัดเจน + เทสต์คุมไว้)
- ชิปเป็นเพียง "ข้อความที่พิมพ์ล่วงหน้า" ไม่ใช่เมนูที่จำกัดสิทธิ์ — แก้/ลบ/พิมพ์ใหม่ได้ตลอด
- placeholder เปลี่ยนจาก "บอกผมมา… เช่น ดู BTC" → **"ถามอะไรก็ได้…"** (ไม่ชี้คำสั่งตายตัว)
- 1 ใน 4 ชิปเป็นคำถามนอกหน้าเสมอ → มาสคอตไม่กลายเป็นปุ่มลัดของหน้านั้นอย่างเดียว

### 4) เร็วขึ้นจริง
- กดชิป 1 ครั้ง = ถาม + ได้คำตอบในบับเบิล ไม่ต้องเปิดหน้าแชท ไม่ต้องพิมพ์
- ถ้าต้องการคุยต่อ: ปุ่มเดิมเปลี่ยนชื่อเป็น **"คุยต่อในแชท"** และพาคำถามล่าสุดไปเติมในช่องแชทให้ (ยังไม่ส่ง)
- ถ้าออฟไลน์: บับเบิลบอกให้เปิดแชทต่อทันที แทนการทิ้งคำถาม

## เทสต์
`src/__tests__/mascotSuggestions.test.tsx` — 11 เทสต์
- ดึงตัวเลขสดมาใช้จริง (BTC 71,858 / drawdown 21.09%)
- เปลี่ยนหน้าต่าง = เปลี่ยนชุดชิป (ยกเว้น universal/explore ที่ใช้ร่วมกันโดยตั้งใจ)
- มีชิป EXPLORE เสมอ และหมุนเวียน (12 seed → มากกว่า 3 คำถามต่างกัน)
- seed เปลี่ยน → ลำดับ/ชุดเปลี่ยน (ปุ่ม "สุ่มใหม่" ไม่ใช่ของหลอก)
- ชิปที่เพิ่งใช้ถูก demote
- ไม่มี id ซ้ำ, ไม่เกิน `max`, ทำงานได้แม้ฟีดว่าง
- ทุก prompt เป็นคำถามธรรมชาติ ไม่ใช่ slash-command; label ≤ 32 ตัวอักษร
- localStorage round-trip + reset
- UI: แถบชิปแสดงตามหน้าต่าง, กดชิปแล้วยิงไป `/api/gemini/mascot-action` ด้วยข้อความของชิป,
  ช่องพิมพ์ยังรับประโยคอิสระที่ไม่เคยมีในเมนู
