## 4. คอมโพเนนต์ที่แก้ตามเล่ม

- **Calm Notice** — `DrawdownAlertBanner.tsx` เขียนใหม่ทั้งไฟล์: แถบพีช-ลาเวนเดอร์บางๆ 1 ประโยค ("พอร์ตย่อตัวลงนิดหน่อย … พักสักครู่ไหมครับ") + ไอคอน + คำ ไม่มีแบนเนอร์แดงเต็มกว้าง ไม่มีกะพริบ ไม่มีคำว่า "เบรกก่อนจิ!"
- **ปุ่ม AI** — ขอบลาเวนเดอร์ 1px แทนนีออนฟ้า (`.mb-neon-edge`)
- **การ์ด** — `.mb-card` พื้น `#1C1F2E` ขอบ 1px เงานุ่ม `0 8px 30px rgba(0,0,0,.25)` มุม 20px; เพิ่ม `.mb-card-hero` (ไล่เฉด Hero) และ `.mb-notice-calm`
- **ชิป / ช่องกรอก** — เพิ่ม `.mb-chip` (999px) และ `.mb-input` (12px)
- **โมชัน** — ถอด `animate-ping` / `animate-bounce` ออกทั้งแอป; แอนิเมชันที่เหลือช้าลงเป็นจังหวะหายใจ 6 วินาที
- **คำต้องห้าม** — "คำสั่งด่วน:" → "ลองถามแบบนี้:"; ปุ่ม `RESET SYSTEM` สีแดง → "เริ่มใหม่ก็ได้ครับ" โทนกลาง

## 7. ที่ยังไม่ได้ทำ (จัดลำดับไว้ให้แล้ว)

1. ธีม **Day Calm** และ **Focus Calm** (Focus = ตัด Glow ตัดมาสคอต ตัดแอนิเมชันพื้นหลัง)
2. **Time-of-Evening** — หน้าจอปรับสีเอง เฟด 20 นาที 18:00 → 21:30 + สวิตช์ปิดในหน้าตั้งค่า
3. ย้าย hex ที่ยังฝังในคลาส Tailwind ไปใช้ `var(--mb-*)` ให้ครบ (ข้อ "ห้าม hardcode สี")
4. **Notification** — เปลี่ยน Badge แดงมีตัวเลขเป็นจุดลาเวนเดอร์ไม่มีตัวเลข + เงียบเป็นค่าเริ่มต้น
5. **Rest Button / Dim to Rest** — หรี่จอเหลือ 35% ใน 800ms แล้วพัก 30 นาที
6. มาสคอต: ห้ามโผล่ตอนเงินหาย / error / เตือนความเสี่ยง — ต้องเพิ่มกฎ suppression ใน `MascotOverlay`
7. ฟีดข่าวจำกัด 12 เรื่อง + ข้อความปิดท้าย "อ่านครบแล้ว พักได้เลย"
8. ฟอนต์ Display เปลี่ยนเป็น **Kanit** ให้ครบทุกหัวข้อ (ตอนนี้ตั้ง `--font-display` แล้ว แต่ยังไม่ได้ใช้กับ h1/h2 ทุกที่)
